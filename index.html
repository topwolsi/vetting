입항예정 데이터 없음

data/arrivals.csv(공급사 제출 입항 일정)를 넣고 프로젝트 폴더에서 python tools/build_fleet_data.py를 실행한 뒤 새로고침하세요.

입항예정 선박

선박을 누르면 선박 검토 화면으로 이동해 심사합니다(입항 1건당 검토 기록 1건). 자동판정은 공급사 제출 정보와 선박 DB로 ETA 기준 5개 카테고리를 미리 판정한 결과이며, 검사 증빙 파일은 있다고 가정합니다. 실제 판정은 검토 화면에서 증빙·사진을 첨부해 확정합니다.
